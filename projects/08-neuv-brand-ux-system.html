Methods

Brand identity, type system, interface system, screen mapping. Built in Figma and Illustrator.

Outcome

A complete fintech identity and interface concept, built for my portfolio and to explore plain-language finance.

The problem

A wave of digital banks and fintech companies was starting up. I wanted to explore the idea underneath them: clarity in finance starts with clarity in design.

Financial products are dense. They handle risk, forecasts and security, and they often explain all three badly. This is a personal concept, not a client job. There was no brief, no user base and no launch.

My role

Everything. I built the brand from naming logic to the custom mark. I chose and paired the type. I designed the layout logic, icon language, colour system and UI hierarchy, and mapped every screen from onboarding to dashboard as one modular system.

Brand positioning, security messaging and capital-fluency framing, three faces of one system

Key decisions

01

A bold logotype with a quiet interface.

Monument Extended for the logotype and display, Neue Montreal for interface labels. The loud face anchors strength. The neutral face lets dense data read cleanly.

02

One modular system, not a set of screens.

Layout, icons, colour and hierarchy are shared rules, so any new screen is built from the same parts.

03

Plain-language forecasts.

Raw numbers are turned into readable sentences. I chose that over adding more charts.

04

Security as the starting point.

The messaging treats encrypted, token-based infrastructure as the default, not an extra.

What changed

Reflection

Neuv is my sandbox: no client, no constraints, just the question of how clear a financial product can feel. It shows I can carry one idea from naming to dashboard as a single system. It also shows the limit of working alone. No user has tested it, and fintech style moves fast, so a rebuild would start with people, not screens.
